# Notas do projeto

Os documentos datados desta pasta são notas arquivadas de planejamento e implementação, registradas em 2026-10-22. Eles preservam pedidos, restrições e decisões de trabalhos anteriores. Não são documentação mantida sobre o produto atual: propostas podem ter mudado, sido substituídas ou nunca ter sido implementadas. Confira o código e as verificações atuais antes de considerar qualquer comportamento descrito neles como vigente.

- [Segurança do perfil clínico e fluxo de trabalho](2026-10-22-seguranca-clinica.md) - requisitos de segurança e fluxo clínico registrados em trabalho anterior.
- [Contas pessoais adicionais](2026-10-22-contas-pessoais.md) - restrições de isolamento e dashboard para contas adicionais.
- [Faturas históricas de cartão](2026-10-22-lancamento-faturas.md) - planejamento para um lançamento pontual de faturas históricas.
- [Conciliação de extratos bancários](2026-10-22-importacao-extratos.md) - escopo e regras registrados para a ferramenta de importação de extratos.
