# Ícone do Podo Agenda

Ícone original criado com a ferramenta integrada de geração de imagens: agenda/gestão em marfim, marca de confirmação e moeda dourada sobre verde, seguindo a identidade do sistema. O original está em `podoagenda-original.png`; as versões PNG foram exportadas em 512, 192, 180 e 32 pixels com reamostragem bicúbica. A versão de 180 pixels fica em `/apple-touch-icon.png`.

O fundo preenche o quadrado e os elementos têm margem para os recortes de ícones do Android. O manifest identifica a versão de 512 pixels como `any maskable`. O sistema do celular aplica o formato externo do ícone.

Prompt utilizado:

> Create a single polished square mobile app icon for Podo Agenda, an appointment scheduling and financial management app. Deliver a flat front-facing icon asset, full-bleed square, 1024 by 1024 pixels. Use a solid deep dollar-green background (#355e46) filling every edge, no rounded outer corners, no transparency. Center a bold, elegant ivory calendar/ledger symbol with two short binder rings and a simple green check mark; overlap its lower-right corner with one warm muted gold coin with a dark green dollar sign. The calendar conveys organization/management and the coin conveys money. Professional restrained financial app aesthetic, crisp geometric vector-like forms, strong silhouette, thick simple shapes legible at small sizes, subtle depth only if helpful. All meaningful foreground elements must be completely contained inside the central 70% diameter circle so Android maskable cropping cannot cut them off; leave generous green space around the symbol. No app name, no words, no additional letters, no watermark, no phone mockup, no multiple icons or grid, no enclosing frame. One ready-to-use app icon.
